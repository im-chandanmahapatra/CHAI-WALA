# Testing & Verification (`tests/`)

Verification scripts and local test procedures for **Chaiwala V2** and **Chaiwala V1 (`client/`)**.

---

## V2 Verification (Active Application)

V2 is a static HTML/CSS/JS site generated by [`v2/tools/build.py`](../v2/tools/build.py) and served locally via [`v2/serve.py`](../v2/serve.py).

### 1. Build Verification

```powershell
python v2/tools/build.py
```

Confirms:
- `MENU` parses cleanly from `v2/app/app.js` (`19` items across `adda`, `y2k`, and `cafe`).
- `v2/assets/{app.js,app.css,landing.js}` compile cleanly (minified with `esbuild` if present).
- All 6 pages (`v2/`, `order/`, `menu/`, `how-it-works/`, `counter/`, `board/`), `404.html`, `sitemap.xml`, `robots.txt`, `llms.txt`, and `site.webmanifest` regenerate without errors.

### 2. Local Runtime & HTTP Range Check

```powershell
python v2/serve.py
```

Verify in a browser or HTTP client:
- `200 OK` on `/v2/`, `/v2/order/`, `/v2/menu/`, `/v2/how-it-works/`, `/v2/counter/` (demo PIN `2580`), `/v2/board/`.
- `200 OK` on `/client/public/audio/2000s-manifest.json` and `206 Partial Content` (`Accept-Ranges: bytes`) on `/client/public/audio/90s_playlist.mp3`.
- Custom `404` page rendered for missing paths.
- End-to-end demo order flow: add items → customize → slide to pay → simulated Razorpay modal → QR token pass → collect in `/v2/counter/`.

## V1 Playwright & QA Suite (`client/`)

### Audio Integration Test Suite (`test_music_integration.py`)

[`test_music_integration.py`](test_music_integration.py) serves `client/dist/` over a local `RangeHTTPRequestHandler` (`127.0.0.1:5195`) and runs 10 Playwright Chromium scenarios covering radio mounting, 1900s playback, 2020s playlist switching, track navigation, seek-bar scrubbing, volume/mute, mobile responsiveness (`390×844`), and console cleanliness.

**Prerequisites:**

```powershell
pip install playwright
playwright install chromium
cd client && npm install && npm run build && cd ..
```

**Run:**

```powershell
python tests/test_music_integration.py
```

### Additional V1 Client Scripts

```powershell
cd client
node .qa-order-tests.mjs   # Order calculation & invariant checks
node verify-ui.mjs         # UI layout verification
```
